    LangGraph¶

    LangGraph models an agent as a graph: nodes are steps (functions or LLM calls), edges are decisions, and all nodes share a typed state. Loops, retries, human approval and multi-agent hierarchies are all just graph shapes.

    # Agent Industry What it does
    02 Agentic RAG Knowledge & RAG Decides when to search a handbook, answers with the section cited
    08 Reflection Agent Agent Patterns Writes, critiques and rewrites its own draft
    13 Corrective RAG Knowledge & RAG Grades retrieved text; falls back to web search when it is irrelevant
    17 Self-RAG Knowledge & RAG Checks its own answer for grounding and usefulness, retries
    21 SQL Agent Data & Analytics Explores a read-only database, writes and fixes SQL
    24 Plan-and-Execute Agent Patterns Plans steps, executes them with a sub-agent, re-plans
    28 Adaptive RAG Knowledge & RAG Routes each question to handbook, web or a direct answer
    31 Supervisor Multi-Agent [Guardrail] Agent Patterns A supervisor routes work to researcher, analyst and writer
    35 Reflexion Agent Agent Patterns Self-critique that triggers web searches, then a revised answer
    38 Customer Support Customer Service Intent routing, order tools, human approval for refunds
    42 Hierarchical Agent Teams Agent Patterns A top supervisor over a research team and a writing team
    45 Code Assistant Software Dev Structured code generation, executed and fixed until it runs
    47 Multi-Agent Collaboration Agent Patterns Researcher and analyst pass the baton until the analyst signs off
    49 Information Gathering Customer Service Asks questions until it can write a prompt template
    57 Bank Statement Analyst Banking Categorises spending, flags unusual transactions, suggests a budget (synthetic data)
