# Agent 56 (extra) - Research Agent as a REST API (FastAPI)

## What it does
Serves a research agent (like agent 01, but with the shared `common/tools.py` web search, which retries other search backends) over HTTP so any program can use it: a website, a mobile app, a script in another language, or `curl`.

| Endpoint | Returns |
|----------|---------|
| `GET /health` | `{"status": "ok", "model": ...}` |
| `POST /ask` `{"question": "..."}` | JSON `{"answer", "model", "tools_used"}` |
| `POST /ask/stream` `{"question": "..."}` | Server-Sent Events: the answer token by token |
| `GET /docs` | Interactive API docs generated by FastAPI |

## Concepts you learn
- **Request/response models:** Pydantic `AskRequest` validates input (3-500 characters) and FastAPI returns a clear 422 error otherwise.
- **Blocking work in an API:** the endpoints are plain `def`, so FastAPI runs each request in a worker thread and the server stays responsive.
- **Streaming with SSE:** `run(..., stream=True)` yields chunks; each is sent as a `data:` event (JSON-encoded, because raw newlines are not allowed inside an SSE data line).
- **One agent per request:** requests don't share conversation history.

## Run
Terminal 1 (server):
```
cd 50-agents-for-all
.venv-agno\Scripts\python.exe protocols\56_research_rest_api\api.py
```
Terminal 2 (clients):
```
curl http://localhost:8000/health
curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d "{\"question\": \"What is RAG?\"}"
.venv-agno\Scripts\python.exe protocols\56_research_rest_api\client.py "What is RAG?"
```
Or open http://localhost:8000/docs and use "Try it out".

## Things to try
- Call the API from JavaScript in a browser page.
- Add an API key check with a FastAPI dependency.

## Known limits
- No authentication or rate limiting: keep it on `127.0.0.1` (the default).
- Each request takes as long as the agent (often 10-30 seconds).
