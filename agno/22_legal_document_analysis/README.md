# Agent 22 - Legal Document Analysis (Agno)

## What it does
Reviews a contract clause by clause from your side (`--side Client` or `--side Provider`): a plain-English summary of each clause, a risk level with a reason, then the top concerns to negotiate. A sample software services agreement is included.

## Concepts you learn
- **Split, then extract:** the first version asked for the whole review in one structured reply and the 7B model returned an empty clause list. Splitting the contract into numbered clauses with a regex and reviewing one clause per call made it reliable. This "chunk, then process each piece" pattern is common in document agents.
- **Two schemas, two passes:** `Clause` for each clause, then `Overview` for parties and top concerns from the collected results.
- **Perspective in the prompt:** the same clause is high risk for one party and low for the other.

## The flow
```
contract -> split into clauses -> [model -> Clause] x N -> clause risks -> model -> Overview -> report
```

## Run
```
cd 50-agents-for-all
.venv-agno\Scripts\python.exe agno\22_legal_document_analysis\main.py
.venv-agno\Scripts\python.exe agno\22_legal_document_analysis\main.py path\to\contract.txt --side Provider
```
Missing/empty file or a file with no numbered clauses exits with code 1.

## Things to try
- Run with `--side Provider` and compare the risk levels.
- Add a clause to the sample (for example an unlimited liability clause) and see it flagged.

## Known limits
- Expects clauses that start with "1.", "2.", ... at the start of a line.
- Clause titles are generated by the model and can be generic ("Clause Review").
- Not legal advice.
